# 面试自测清单（CodePilot）

> 用法：**盖住答案，只看问题**，出声讲 60 秒。讲不下去的题打 ❌，那就是要补的——或者把对应的简历表述删掉。
> 完整答案在 [`interview-guide.md`](interview-guide.md)。
>
> 每题后面只有**关键词提示**，不给答案。能靠关键词讲出完整逻辑，才算会。

## 四、5 分钟快问快答（每题 15 秒）

1. 这个项目解决谁的什么问题？
2. 一次审查从触发到发布经过几步？
3. 门禁为什么只信确定性规则？
4. 模型轮次和工具调用双限额，各自上限是多少？
5. 生产上 PUBLISH 和 SUPPRESS 各多少？
6. 真模型评测的 24 个场景里，跳过了哪几类？
7. 什么时候会把 PR 标成 UNCHANGED？
8. 如果没有配 embedding 会怎样？
9. 审计里能查到什么？
10. 演示 PR 现在的 mergeable_state 是什么？

---

## 自评结果怎么用

- **全 ☐ 打勾** → 去投，别改了。
- **有 1~3 个 ❌** → 只补这几个问题，不要回头改项目。
- **超过 5 个 ❌** → 说明简历写了讲不清的东西，**先删简历条目**，再补。

> 记住帖子里那句：**“没有准备好的就不要往上写”**。被问穿比不写更伤。
